# Endringslogg

## 0.1.0

- Første versjon: barneprofiler, registrering av temperatur, medisin, symptomer og notat.
- Legemidler per barn med vanlig dose, minste intervall, maks døgndose og kur. Døgndose summeres per virkestoff (rullerende 24 t).
- Automatiske sykdomsepisoder med feberkurve, oppsummering per dag og utskrift.
- Import fra kalendere i Home Assistant med duplikatfjerning, sammenslåing og gjennomgang.
- Sensor per barn, skjermtekst, hendelser og valgfri varsling.
