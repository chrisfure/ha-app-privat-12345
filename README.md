# Apper for Home Assistant

Små apper for familiehverdagen, laget for Home Assistant.

| App | Hva den gjør |
|---|---|
| [Babyuret](babyuret/DOCS.md) | Registrer babyens søvn, mat og bleier – raskt nok til å brukes med én hånd klokka tre om natta. |
| [Plasterboka](plasterboka/DOCS.md) | Sykdomslogg for barna: temperatur, medisin og symptomer med ett trykk, døgndose per legemiddel og sykehistorie med feberkurver. |

## Installering

1. I Home Assistant: **Innstillinger → Apper → App-butikk → ⋮ → Repositories**.
2. Legg til adressen til dette repoet.
3. Installer og start appen du vil bruke.
4. Åpne den fra sidemenyen og legg inn det som trengs under **Innstillinger** i appen.

## Babyuret – planlagt

1. ✅ Grunnmur: registrering, lagring, sensorer og hendelser
2. ✅ Søvnprognose, normalområder per alder og målinger med vekstkurver
3. Ukegrafer og trender
4. Ukentlig AI-kalibrering og ukerapport
5. Ekstra automasjoner: nattlys ved mating, «baby sover»-modus, bleier til handlelisten

Anbefalinger og normalområder er hentet fra Helsenorge, Helsedirektoratet og WHO – se kildelistene i hver app.

Ingen personlige opplysninger ligger i koden – navn, datoer og helsedata settes inne i appene og lagres lokalt.
