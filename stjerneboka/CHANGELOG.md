# Endringslogg

## 0.1.0

- Første versjon: barn, oppgaver med tegning/emoji/eget bilde, tre typer (rutine, familiebidrag, ekstra innsats) og 1–3 poeng.
- Barneside på egen port for veggskjermen: store bilder, stor stjerne når noe er gjort, rakett og angre-knapp.
- Godkjenning av krevende oppgaver – i appen eller med knapper i varselet på mobilen.
- Ukepenger som kan slås på senere: oppgaver kan gjøres om til pengeoppgaver, kroner per poeng og «betal ut» per uke.
- NFC-kort: skann et nytt kort og koble det til barn og oppgave inne i appen.
- Fanfare og stemme via Music Assistant eller tekst-til-tale, og barnesiden kan åpnes på veggskjermen med Browser Mod.
- Sensor per barn og hendelsen «stjerneboka_hendelse» til egne automasjoner.
